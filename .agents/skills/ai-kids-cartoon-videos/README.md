# AI Kids Cartoon Videos, with Claude + Higgsfield

A free **Claude skill** that generates complete animated nursery-rhyme kids videos end to end: an original character, a catchy sing-along song, and a full set of bright 3D scenes. Built for faceless **YouTube Kids** channels you can post to every day, no face, no manual animation.

Kids channels pull hundreds of thousands of views per video, and YouTube pays roughly **$200 to $3,000 per 100,000 views**. One repeatable character plus a daily upload is a channel that compounds.

## How to use it

1. In Claude (claude.ai), go to **Settings, then Connectors, then Add custom connector**.
2. Copy the link from **higgsfield.ai/mcp**, paste it in, and name it **Higgsfield**.
3. Open [`SKILL.md`](./SKILL.md), paste it into a Claude Project (or as custom instructions), and run the **Master Prompt**.

That is it. Claude plans the character, writes the song, and drives Higgsfield to generate every scene.

## Read first

This builds **original** characters and songs. Do not copy real, trademarked characters, names, or songs from existing kids brands. Always set **"Made for Kids"** on upload, and keep every video gentle and wholesome. Full rules are in the [Safety and policy](./SKILL.md#safety-and-policy-read-this-before-posting) section.
